# How-to guides

Recipes for making a game on Lupine 3D. Each names the files to touch, the
limits that apply and the checks that prove the change. Run commands from
the repository root, in the virtual environment, with `--game` naming your
game (`games/my_game` below).

| Guide | When you want to |
|---|---|
| [Add a level](add-a-level.md) | draw a level, get it certified and put it in the campaign |
| [Use Tiled](use-tiled.md) | edit a level in the Tiled map editor |
| [Episodes and progression](episodes-and-progression.md) | order the campaign, add episodes and their screens, unlock weapons |
| [Enemies](enemies.md) | define enemy kinds and field them |
| [Weapons](weapons.md) | change the four weapons, their numbers and their sheets |
| [Themes and palettes](themes-and-palettes.md) | recolour the world, add a theme |
| [Wall textures](wall-textures.md) | draw a wall texture and give it a role |
| [Sprites and the HUD](sprites-and-hud.md) | redraw sprites, the HUD chassis, the portrait, the HUD's words |
| [Screens](screens.md) | rewrite the title, results and episode screens |
| [Music and sound](music-and-sound.md) | write songs and shape sound effects |
| [Test your game](test-your-game.md) | check content, approve goldens, play it through, run the cores |
| [Debug a build](debug-a-build.md) | look inside the ROM with symbols, the harness and the cores |
| [Ship a ROM](ship-a-rom.md) | build a release and tell players what they need |
| [Troubleshooting](troubleshooting.md) | understand a refusal and fix it |

Changing the engine itself is in [engine development](../engine/README.md).
