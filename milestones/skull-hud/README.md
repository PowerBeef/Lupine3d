# Initial skull and objective revision

This retained evidence describes ROM
`d377b4d38c9130260beff17c11db9fe78ba2a6f71cf29ba9f63d786c7cddc33e`:
the enemy silhouette was replaced by a skull, and EXIT LOCK/OPEN became
GOAL HUNT/EXIT. It predates the subsequent one-pixel text adjustment.

The current implementation and qualification are in
[hud-spacing](../hud-spacing/). Reports here remain bound to the earlier ROM;
do not use them as current performance or safety evidence.
